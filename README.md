# Bulk Email Sender — Next.js Frontend Migration

## Overview
This project is a frontend migration of the Bulk Email Sender app from vanilla HTML/CSS/JS to **Next.js** with TypeScript and Tailwind CSS.

Backend is kept completely unchanged as per assignment requirements.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS



## Setup & Run

```bash
npm install
npm run dev
```

Open: http://localhost:3000
